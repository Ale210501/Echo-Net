The command to enable and configure OT ambushes on a container running on Conpot OT can be configured using the "ot_container_status" event. This event is sent out once an amenable container has been started, and provides details about its status at that time. Here are the steps to enable and configure OT ambushes using the "ot_container_status" event:

1. First, open a PowerShell or SSH session on your Conpot OT container using command `docker exec -it <CONOPT-POD-NAME> /bin/bash`.

2. In the SSH terminal, run the following commands:

```
sudo su
sudo apt update && sudo apt install curl -y
curl -s "https://raw.githubusercontent.com/conpot-inc/evm-onboarding/master/scripts/ot_container_status.sh" | bash -s conpot_dynamic 1861fb518487
```

3. Open a new Powershell or SSH session on your host machine using command `docker exec -it <CONOPT-POD-NAME> /bin/bash`.

4. In the PowerShell terminal, create an empty file in the container's work directory (cd ~/ot_container_status) and run the following commands to configure OT ambushes:

```
@<|system-Net\\\\observatory\\\\ot\\\\conpot>
{
  "event": "ot_container_status",
  "timestamp": "2026-08-07T15:15:52.485492+00:00",
  "status": "started",
  "detail": "Conpot OT ambush is active.",
  "container_name": "conpot_dynamic",
  "container_id": "1861fb518487",
  "volume_host_dir": "/var/log/conpot",
  "volume_container_dir": "/var/log/conpot"
}
```

This configuration will allow Conpot OT to send notifications for every time a container on the host machine is active (started or stopped), and provide detailed information about its status (i.e., whether the amenable container has successfully started, or if there are any errors). It can be used by monitoring tools like InfluxDB or Grafana to visualize these metrics for better understanding of Conpot OT's behavior. Once configured, Conpot OT will send regular "ot_container_status" events with detailed information about its status to the specified destination.
