The Echo-Net observatory provides a RESTful API endpoint for retrieving detailed information about the status and behavior of each individual container and its corresponding pods. The JSON response includes key data such as the name, container ID, and timestamp when the container was created/updated or forensic snapshot was exported/retrieved. In addition to these metrics, the API endpoint returns information about the current state of each container's persistence volume as well as its associated network interfaces.

The JSON response is structured as follows:
```
[
    {
        "event": "ot_container_recreated",
        "timesamp": "2026-08-07T07:57:27.019216+00:00",
        "status": "recreated",
        "container_name": "conpot_dynamic",
        "container_id": "1861fb518487"
    },
    {
        "event": "ot_forensics_snapshot_exported",
        "timesamp": "2026-08-07T07:57:28.237335+00:00",
        "export_file": "C:\\Users\\ale20\\OneDrive\\Desktop\\Echo-Net\\observatory\\ot\\exports\\conpot_forensics_20260807_075728.json"
    }
]
```

The following key metrics are available for each container:
1. Name: The name of the container as specified in the Echo-Net observatory configuration file.
2. Container ID: The unique identifier of the container, which is generated by the system when a new container is created.
3. Timestamp: The time at which the current state was recorded.
4. Status: The current status of the container as indicated in the Echo-Net observatory configuration file. Possible values include "running", "succeeded", and "failed".
5. Container name: The name of the container's pod, which is specified in the Echo-Net observatory configuration file.
6. Container ID: The unique identifier of the container's pod, which is generated by the system when a new pod is created.
7. Volume host directory: The path to the persistent volume mounted for the container's data. If no persistent volume was defined in the Echo-Net observatory configuration file, this value will be null or empty.
8. Volume container directory: The path to the persistent volume container directory as specified by the Echo-Net observatory configuration file. This may differ from the volume host directory if the volume is mounted in a different container than its associated pod.
9. Timeout: The time at which the forensic snapshot export process will be terminated.
10. Network interfaces: A list of network interfaces associated with the container as specified by the Echo-Net observatory configuration file. Each interface includes information such as name, mac address, and IP address.
11. Properties: The Echo-Net observatory provides various properties for each container such as CPU usage, memory usage, and network traffic. These metrics are available in JSON format along with the container's timestamp and status information.
